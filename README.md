# 📱 Телефонмен монтаж: Claude Code

Компьютерсіз, тек телефонмен Reels/TikTok монтаждау. Сен Claude-қа не керек екенін жазасың, ол бұлттағы компьютерде видеоны монтаждап береді.

---

## Не керек

- **Claude Pro** (немесе Max) жазылымы. Тегін тарифте бұл жұмыс істемейді
- **GitHub** аккаунты (тегін): github.com
- **Claude** қосымшасы (App Store / Google Play)
- **Google Drive** (видеоны жіберу үшін)

---

## Бір реттік баптау (15 минут)

### 1-қадам. Осы шаблонды өзіңе көшіру
1. Телефон браузерінде осы беттің жоғарғы жағындағы **Use this template → Create a new repository** батырмасын бас.
2. Атын жаз (мысалы `montazh`), **Private** таңда, **Create repository** бас.

### 2-қадам. Claude-ты GitHub-қа қосу
1. Claude қосымшасын аш → **Code** бөлімі.
2. Бірінші рет кірсең, GitHub-қа қосылуды сұрайды: рұқсат бер.
3. Репозиторий тізімінен өзіңнің `montazh` репозиторийіңді таңда.

### 3-қадам. Бұлт компьютерін баптау (ең маңызды!)
Code бөлімінде environment (орта) таңдайтын жерді аш → баптау белгісі (⚙️):
1. **Network access → Full**. Бұл болмаса, Claude видеоңды Drive-тан ала алмайды.
2. **Setup script** өрісіне мына мәтінді толық көшіріп қой:
   ```bash
   apt-get update -qq
   apt-get install -y -qq ffmpeg
   npm install -g hyperframes@latest || true
   npx -y hyperframes skills update || true
   ```
3. **Save** бас.

Болды, баптау бітті. Мұны қайталаудың қажеті жоқ.

## Әр видеоны монтаждау

### 4-қадам. Видеоны Drive-қа салу
1. Видеоны Google Drive-қа жүкте.
2. Файлдың ⋮ мәзірі → **Бөлісу (Share)** → **Жалпы рұқсат: Сілтемесі бар кез келген адам** → **Сілтемені көшіру**.

### 5-қадам. Claude-қа жазу
Claude → Code → `montazh` репозиторийі → жаз:

> Мына видеоны менің стилімде монтажда: *(сілтемені қой)*

Claude видеоны жүктеп, мәтінін сұрауы мүмкін («не айтқаныңның мәтіні бар ма?»). Мәтінің болса, жібер: субтитр дәлірек шығады.

Монтаж 5–20 минут алады. Қосымшаны жауып қоя бер, дайын болғанда кіріп қара.

### 6-қадам. Дайын видеоны жүктеп алу
1. Claude «Видео дайын, **claude/...** branch-та» деп жазады.
2. Телефон браузерінде github.com → өзіңнің репозиторийің → жоғарыдағы **branch** тізімінен сол branch-ты таңда.
3. `output` папкасы → видео файлы → **⋯ → Download** (немесе **View raw**, сосын видеоны ұзақ басып, сақта).

### 7-қадам. Түзету
Ұнамаған жерін жай сөзбен жаз, Claude түзетіп, жаңа нұсқа жасайды. Дайын сөйлемдер: [PROMPTS.md](PROMPTS.md).
